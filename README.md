# 🛡️ CyberQuest

CyberQuest is an interactive cybersecurity learning game designed to make cybersecurity education fun, engaging, and practical.

## 🎮 Features

- 🔐 User Registration & Login
- 🌍 10 Cybersecurity Worlds
- 🎯 100 Progressive Missions
- ⭐ XP, Points & Coins
- ❤️ Lives System
- ⏱️ Timed Challenges
- 🏆 Level Progression
- 📊 Player Dashboard
- 💾 MySQL Database
- ☕ Java Spring Boot Backend
- 🌐 HTML, CSS & JavaScript Frontend

## 🗺️ Worlds

1. Cyber Origins
2. Phishing Bay
3. Fortress Login
4. Social Trap
5. Web City
6. Mobile Zone
7. Malware Island
8. Response Command
9. Threat Hunter
10. Cyber Guardian
